# Python DevOps Toolkit

A collection of Python scripts designed to simulate real-world DevOps tasks such as log analysis, basic monitoring, and automation.

---

## 📌 Project Overview

This project demonstrates how Python can be used in DevOps environments to automate operational tasks and analyze system behavior.

The current implementation focuses on parsing application logs to detect errors and provide basic insights into system health.

---

## 🧠 Real-World Use Case

In production environments, applications generate logs continuously. DevOps engineers use these logs to:

- Identify system failures
- Debug application issues
- Monitor system health
- Trigger alerts for critical errors

This project simulates that workflow by analyzing a log file and detecting error patterns.

---


## 🛠️ Tech Stack

- Python 3
- File handling and parsing
- Basic automation scripting

---

## 📂 Project Structure

- log_parser.py # Parses logs and detects errors
- metrics_checker.py # Simulates CPU monitoring logic
- app.log # Sample log file

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/MoiseGermain/python-devops-toolkit.git
cd python-devops-toolkit
```

2. Run the script:
   
```bash
python log_parser.py

```
