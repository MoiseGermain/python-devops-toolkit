# Python DevOps Toolkit

A collection of Python scripts designed to simulate real-world DevOps tasks such as log analysis, basic monitoring, and automation.

---

## 📌 Project Overview

This project demonstrates how Python can be used in DevOps workflows to:

- Parse and analyze application logs
- Detect errors and anomalies
- Simulate system monitoring logic
- Automate simple operational tasks

This serves as a foundational step toward building more advanced systems like CI/CD pipelines, observability stacks, and AIOps solutions.

---

## 🛠️ Tech Stack

- Python 3
- File handling
- Basic scripting and automation

---

## 📂 Project Structure

- log_parser.py # Parses logs and detects errors
- metrics_checker.py # Simulates CPU monitoring logic
- app.log # Sample log file
---


---

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/MoiseGermain/python-devops-toolkit.git
cd python-devops-toolkit
```

2. Run the script:
   
```bash
python log_parser.py

```
